KC-CXIM(《铖信》即时通讯)

KC-CXIM《铖信》是一个面向学习与二次开发的全栈即时通讯项目：自带 C++17 自研 IM 服务端（HTTP 鉴权 + TCP 长连接 + MariaDB）、Windows 桌面客户端与 Web 管理后台（Drogon 后端 + Vue3 前端），同时保留腾讯云 IM SDK 的接入示例。

KCMemMonitor(克铖内存监控器)

基于 C++ 与 WinUI3 的 Windows 整机物理内存监控工具。界面实时展示总内存、已用内存、可用内存、占用百分比与内存压力等级五项指标，并以环形饼图和近 60 秒动态趋势图直观呈现。

KCCPUMonitor(克铖CPU性能监控器)

本项目是基于 C++ 与 WinUI3 的 Windows 整机 CPU 性能监控工具，WinUI3 桌面应用，实时展示 CPU 名称、利用率、当前/基准频率、进程数、线程数、句柄数、正常运行时间、插槽、内核、逻辑处理器、虚拟化状态、L1/L2/L3 缓存。
